# parse-fit-json

# como ejecutar el programa

### Pasos:
Clona el repo desde la terminal con este comando: 
```
git clone https://github.com/duvanzm/parse-fit-json.git
```
luego usa este comando para abrirlo en VSC

```
cd parse-fit-json
code .
```

### copia y pega en la terminal para instalar las dependencias

```
cd express
npm install express multer fit-file-parser cors
```

### corre el servidor 

```
node server.js
```

### Por ultimo abre el archivo index en un navegador
